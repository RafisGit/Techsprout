## 2. Product Decisions Codified

| Decision | Status | Technical Implementation in P5.5.1 |
|---|---|---|
| **PD-1: Refund Policy Window** | **APPROVED** | Defined `REFUND_POLICY_WINDOW_DAYS = 7`, `REFUND_POLICY_WINDOW_HOURS = 168`, and `REFUND_POLICY_WINDOW_MS = 604,800,000` in `@techsprout/contracts`. Validated server-side against `order.paidAt`. |
| **PD-2: Course Progress Limit** | **APPROVED** | Defined `REFUND_MAX_PROGRESS_PERCENTAGE = 20` (strictly `< 20%` required). Check constraint `refund_requests_progress_range` (`0 <= progress <= 100`) enforces data integrity. |
| **PD-3: Multiple Refund Requests** | **APPROVED** | Created partial unique index `refund_requests_active_order_uq` ON `refund_requests (order_id)` WHERE `status IN ('PENDING', 'APPROVED')`. Guarantees exactly one active request while permitting resubmission after `REJECTED`. |
| **PD-4: Tax / VAT Presentation** | **APPROVED** | Financial contracts retain standard authoritative fields (`subtotalCents`, `discountCents`, `payableCents`, `currency: 'BDT'`). Zero synthetic VAT/tax fields injected. |
| **PD-5: Certificate Revocation** | **APPROVED** | Preserved P5 `RefundsService.atomicFinalizeRefund` certificate revocation behavior (`status = 'REVOKED'`, `revocationReason = 'Order refunded'`). |

Defined in [`apps/api/src/database/schema/refund-requests.ts`](file:///d:/Work/2026/techsprout-main/apps/api/src/database/schema/refund-requests.ts):

- `order_id`: `uuid` not null references `orders(id)` ON DELETE restrict
- `student_id`: `uuid` not null references `users(id)` ON DELETE restrict
- `course_id`: `uuid` not null references `courses(id)` ON DELETE restrict
- `enrollment_id`: `uuid` not null references `enrollments(id)` ON DELETE restrict

- `reason_detail`: `text` not null (checked >= 10 chars)
- `course_progress_at_request`: `integer` not null (checked between 0 and 100)
- `status`: `refund_request_status` default `'PENDING'` not null
- `reviewed_by`: `uuid` references `users(id)` ON DELETE restrict
- `reviewed_at`: `timestamp with time zone`
- `rejection_reason`: `text`
- `admin_notes`: `text`
- `refund_id`: `uuid` references `refunds(id)` ON DELETE restrict
- `created_at`: `timestamp with time zone` default `now()` not null
- `updated_at`: `timestamp with time zone` default `now()` not null

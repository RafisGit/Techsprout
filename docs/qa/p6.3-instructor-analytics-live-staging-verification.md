- **Source-Code Configuration:** Source-code audit of `apps/api/src/modules/analytics/analytics.service.ts` and `analytics.cache.service.ts` confirms the cache implementation uses `ioredis`, a 600-second TTL (`ttlSeconds: 600`), and tenant-scoped keys (`instructor:analytics:overview:${id}`, `course:analytics:${id}:${rangeHash}`).

Render Shell is unavailable on the current Free compute plan, staging Redis is locked to a private VPC with `ipAllowList: []`, and the application REST API emits no cache diagnostic headers or hit logs. Therefore, live Redis key existence, TTL, and cache-hit behavior could not be independently inspected and are formally classified as **`NOT VERIFIED — SAFE DIRECT OBSERVABILITY UNAVAILABLE`** (see consolidated staging report).

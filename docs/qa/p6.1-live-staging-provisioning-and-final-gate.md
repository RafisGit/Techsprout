## 6. Database Isolation

The architecture enforces strict physical and logical separation:

1. **Independent Instance Declarations:**
   - Production: `techsprout-postgres` (Database: `techsprout`, User: `techsprout`)
   - Staging: `techsprout-postgres-staging` (Database: `techsprout_staging`, User: `techsprout_staging`)
2. **Environment Variable Injection:**
   - In `render.yaml`, `techsprout-api-staging` binds `DATABASE_URL` via `fromDatabase: { name: techsprout-postgres-staging, property: connectionString }`.
   - Staging has zero reference or network path to the production PostgreSQL cluster.
3. **Hard Safety Verification:**
   - Production credentials remain unmodified in `render.yaml`.
   - Staging migration execution will only target `DATABASE_URL` resolved from `techsprout-postgres-staging`.

---

## 7. Redis Isolation

1. **Independent Key-Value Stores:**
   - Production: `techsprout-redis`
   - Staging: `techsprout-redis-staging`
2. **Network Restrictions:**
   - Both stores declare `ipAllowList: []`, restricting all TCP ingress exclusively to services within the same Render private network namespace.
3. **Queue Cross-Contamination Protection:**
   - BullMQ worker in staging will connect strictly to `techsprout-redis-staging`.
   - Staging background jobs (`notification.in_app`, `notification.email`) cannot pollute or trigger execution within production worker pools.

---

## 8. Session Isolation

1. **Independent Secret Generation:**
   - In `render.yaml`, both `techsprout-api` and `techsprout-api-staging` define:
     ```yaml
     - key: AUTH_SECRET
       generateValue: true
     ```
   - Render generates cryptographically random 256-bit secrets independently for each service.
2. **Cross-Environment Token Invalidation:**
   - A JWT signed by the staging `AUTH_SECRET` will fail signature verification against production with `401 Unauthorized` (`INVALID_TOKEN`).
   - A JWT signed by the production `AUTH_SECRET` will fail signature verification against staging with `401 Unauthorized` (`INVALID_TOKEN`).

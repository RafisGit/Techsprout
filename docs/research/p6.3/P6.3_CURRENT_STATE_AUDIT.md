## 1. Executive Summary

This audit establishes the definitive baseline of the TechSprout LMS repository prior to initiating Milestone P6.3 (Learning Analytics). The audit inspects all transactional entities, API controllers, services, database schemas, frontend components, shared contracts, and test fixtures relevant to learning telemetry, instructor overview metrics, and administrative reporting.

### Key Audit Findings:
1. **Client-Side Computed Instructor Dashboard:** The existing `/instructor/dashboard` route calculates portfolio counts entirely in browser memory from a generic course query (`fetchInstructorCourses({ limit: 100 })`). No backend metric aggregation endpoint currently exists for instructors.
2. **N+1 Database Query Bottleneck in Learner Roster:** The endpoint `GET /api/v1/admin/courses/:id/enrollments` executes duplicate and serial database queries for every row returned: for each student, it queries the course's total lesson count and the individual student's completed lessons, yielding $2N + 2$ queries per roster fetch.
3. **Confirmed Production UX Limitation (`DEF-P6.2-UX-01`):** In `LearnerRosterClient.tsx`, student name and email search is applied strictly against the currently loaded page (default 10 items). The backend endpoint lacks a `search` query parameter, preventing server-side search across pagination boundaries.
4. **Historical Data Richness vs. Event Telemetry Absence:** PostgreSQL already stores rich transactional data in `enrollments`, `lesson_progress`, and `quiz_attempts`. However, the append-only `learning_events` table proposed in `ADR-P6-003` has not been implemented or migrated.
5. **No Charting Dependency Installed:** `apps/web/package.json` contains no charting library (e.g., Recharts, Chart.js, or Nivo). Existing administrative metrics (in `/admin/finance`) utilize Tailwind KPI stat cards and data tables.
6. **Production Deployment Discrepancy:** While P6.2 was merged to `origin/main` (`4c17bdc`), production Render API still serves the P6.1 baseline (`GET /api/v1/instructor/courses` returns 404). Migration `0007_instructor_platform_foundation.sql` is pending production execution.

    // Query 1: Total lessons count for course (Executed repeatedly N times for the same course!)
    const [totalResult] = await this.db
      .select({ count: count(lessons.id) })
      .from(lessons)
      .innerJoin(modules, eq(lessons.moduleId, modules.id))
      .where(eq(modules.courseId, courseId));

    // Query 2: Completed lessons count for this specific enrollment
    const [completedResult] = await this.db

      .innerJoin(modules, eq(lessons.moduleId, modules.id))

## 5. Identified Gaps and Deficiencies for P6.3

| Gap ID | Domain | Observed Limitation | Root Cause | Impact on P6.3 Analytics |
|---|---|---|---|---|
| **GAP-01** | Instructor API | No dedicated instructor analytics endpoint | Omitted from P6.2 scope | Instructor overview metrics must be computed from raw course lists |
| **GAP-02** | Roster Query | N+1 database queries in `getAdminCourseEnrollments` | Uncached serial `calculateCourseProgress` calls | Query latency degrades linearly with roster size |
| **GAP-03** | Roster Search | Search is client-side and scoped to loaded page (`DEF-P6.2-UX-01`) | Backend query lacks `search` parameter | Cannot search across multi-page rosters |
| **GAP-04** | Indexing | Missing composite index on `enrollments(course_id, enrolled_at)` | Omitted in migration 0003 | Time-series date range filters perform sequential index/table scans |
| **GAP-05** | Telemetry | No append-only event logging table (`learning_events`) | ADR-P6-003 deferred to P6.3 | Video drop-off curves cannot be measured at fine temporal resolution |
| **GAP-06** | Visualization | Zero charting libraries installed | No visual graphing was required in P1-P6.2 | Analytics UI requires either lightweight SVG charting or approved package |
| **GAP-07** | Admin Overview | `/dashboard/admin/overview` contains static placeholders | Initial prototype was never connected | Administrators lack catalog-level course and enrollment summaries |
| **GAP-08** | Student Overview | `/dashboard` displays hardcoded zeroes | Deferred in Phase 3 | Students cannot view real enrollment and completion counts |

## 1. Executive Summary & Benchmark Verdict

Pursuant to senior engineering authorization for a final, time-boxed lexical search experiment, four distinct advanced lexical retrieval configurations were systematically benchmarked across an expanded synthetic curriculum corpus of **53,960 words** (472,478 characters) spanning **11 courses** and **100 lessons** within an isolated PostgreSQL 14 instance simulating Render Free database tier constraints (0.1 shared vCPU, 256 MB RAM ceiling, 64 MB `shared_buffers`).

The primary objective was to determine whether domain-specific synonym expansion, field-aware technical token normalization, wider candidate pooling, and Reciprocal Rank Fusion (RRF) could push **Recall@5 to $\ge 0.85$** while preserving **NDCG@5 $\ge 0.80$**, **0 zero-result drops**, and **$p95 < 50\text{ ms}$**.

## 3. Synthetic Corpus & Evaluation Methodology

### 3.1 Corpus Scope
The benchmark was conducted across the full 11-course platform curriculum expanded to **53,960 words** (472,478 characters) across **100 lessons** (average 539.6 words per lesson):
- Courses 1–10: 9 lessons each.
- Course 11 (Kubernetes Microservices): 10 lessons.

### 3.2 Tested Configurations

#### Configuration A — Control (Existing Hybrid Pipeline)
- Strict FTS (`websearch_to_tsquery('english', $1)`) over weighted `tsvector` (Weight A: Title/Course, Weight B: Module, Weight C: Content).
- Controlled query relaxation (strip conversational stop words, bounded OR disjunction) if $< 5$ matches.
- `pg_trgm` fuzzy fallback (`word_similarity >= 0.30`) if $< 5$ matches.
- Tier-based deduplicated ranking (Strict $\rightarrow$ Relaxed $\rightarrow$ Trigram).

#### Configuration B — Domain-Specific Synonym Rings
- Incorporates a curated full-stack curriculum vocabulary mapping domain synonyms without query-specific overfitting:
  - Infrastructure: `docker` $\leftrightarrow$ `container`, `k8s` $\leftrightarrow$ `kubernetes` $\leftrightarrow$ `cluster`.
  - Database: `postgres` $\leftrightarrow$ `postgresql` $\leftrightarrow$ `rdbms`, `orm` $\leftrightarrow$ `drizzle`.
  - Frontend: `react` $\leftrightarrow$ `components` $\leftrightarrow$ `hooks`, `css` $\leftrightarrow$ `layout` $\leftrightarrow$ `grid` $\leftrightarrow$ `flexbox`.
  - Security & Payments: `auth` $\leftrightarrow$ `jwt` $\leftrightarrow$ `authentication`, `gateway` $\leftrightarrow$ `sslcommerz` $\leftrightarrow$ `payment`.
- Query expansion transforms core tokens into bounded synonym disjunctions `(token | syn1 | syn2)`.

#### Configuration C — Field-Aware Technical Token Normalization
- Pre-indexes both punctuated compound tokens and constituent word stems:
  - `ci/cd` $\rightarrow$ indexes both `'ci/cd'` and `'ci'`, `'cd'`.
  - `node.js` $\rightarrow$ indexes `'node.js'`, `'nodejs'`, and `'node'`.
  - `http-only` $\rightarrow$ indexes `'httponly'` and `'http-only'`.
- Preserves technical identifiers with Weight A/B while retaining English Snowball stemming on lesson body content (Weight C).

#### Configuration D — Wider Candidate Pooling & Reciprocal Rank Fusion (RRF)
- Queries multiple independent retrieval channels:
  - Channel 1: Strict Technical FTS ($w_1 = 1.0$)
  - Channel 2: Relaxed Synonym Disjunction ($w_2 = 0.8$)
  - Channel 3: Trigram Word Similarity ($w_3 = 0.6$, threshold $= 0.28$)
- Evaluates candidate pool sizes $K \in [20, 50, 100]$.
- Combines candidates via Reciprocal Rank Fusion ($k = 60$):
  $$Score(d) = \sum_{m \in \{1, 2, 3\}} w_m \cdot \frac{1}{60 + r_m(d)} + \text{TitleMatchBoost}(d)$$
  where $\text{TitleMatchBoost} = 0.05$ if the lesson title contains an exact match for the technical query.

### Why Lexical Search Cannot Achieve Recall@5 $\ge 0.85$
1. **The Vocabulary Mismatch Problem:** In multi-lesson curriculum structures, lessons teaching foundational or prerequisite concepts often share zero vocabulary with the main lesson. For example, Lesson 55 covers `"Transactional Outbox and Debezium Change-Data Capture"`, while Lesson 35 covers `"Event-Driven Outbox Pattern in NestJS"`. Lexical search cannot infer that `"Debezium CDC"` is a direct application of the `"Outbox Pattern"` without co-occurring terms.
2. **False-Positive Trade-off:** Relaxing thresholds further to capture distant lessons introduces noise that degrades NDCG@5 and dilutes top-rank precision.
3. **Conclusion:** Lexical search has reached its theoretical Pareto frontier at **NDCG@5 = 0.8863** and **Recall@5 = 0.7448**. Pushing Recall@5 to $\ge 0.85$ requires dense semantic vector representations.

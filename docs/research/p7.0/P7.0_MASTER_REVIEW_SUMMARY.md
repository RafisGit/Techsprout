## 1. Executive Architecture Summary

This master synthesis establishes the authoritative baseline for transitioning TechSprout from Phase 6 into Phase 7. 

Phase 6.3 (Analytics & Reporting Platform) was formally promoted to production and verified at commit `491b0d055f14a84bfcce45c0576c685f1017d661`, with all 45 recorded smoke tests passing and operational limitation `WVR-P6.3-CACHE-01` (Redis shell unobservability on Render Free plan) formally accepted.

### Core Strategic Findings:
1. **Verified Codebase Baseline:** The monorepo has a strong transactional foundation (1,507 passing automated tests, zero-trust resource ownership, Drizzle ORM migrations 0000–0008, Cloudinary signed media, and single-merchant SSLCommerz payments). However:
   - Client progress tracking in `VideoPlayer.tsx` suffers from an unmount exit defect (asynchronous axios call in cleanup cancelled during page unload).
   - Progress updates overwrite state in-place in `lesson_progress`, and the append-only `learning_events` table is **strictly absent**.
   - `OutboxService` operates as an uncoordinated, best-effort dual-write pattern (non-transactional emit, persistence errors swallowed, zero background replay/reconciliation crons).
   - Rate limiting is purely global (100 req/60s per IP via `ThrottlerModule`), with zero per-user or per-lesson server limits. Client-side throttling (60s in `VideoPlayer.tsx`) is strictly supplemental defense-in-depth; client event UUIDs provide duplicate-event idempotency (same payload returns HTTP 200/204 with 0 duplicate rows; differing payload rejected as HTTP 409 conflict) rather than full replay protection. Mandatory server-side per-user/lesson throttling, authorized enrollment and entitlement verification (including legitimate free/zero-payable courses), temporal/duration bounding, payload validation, and strict protection of server-authoritative completion/certificate invariants are required controls for P7.1.
2. **Scope Reallocation Ratified (Option B via SCR-P7-01):** Senior Engineering Leadership approved Scope Change Request [`SCR-P7-01`](file:///d:/Work/2026/techsprout-main/docs/research/p7.0/SCR-P7-01_SCOPE_CHANGE_REQUEST.md) on October 17, 2026. Milestone P6.4 (Discussions & Assignments) is formally reassigned to **Phase 7.4** (5.5 / 7.0 / 9.0 days), strictly scheduled after telemetry, AI tutoring, and instructor monetization. Phase 7.1 remains strictly confined to Learning Telemetry & Retention Analytics (6.5 / 9.0 / 12.0 days).
3. **Phased Roadmap Over Monolithic Delivery:** Phase 7 is restructured into focused sub-phases:
   - **Phase 7.1 — Learning Telemetry & Retention Analytics (6.5 / 9.0 / 12.0 Days) [CONDITIONALLY APPROVED]**
   - **Phase 7.2 — AI Tutoring & Contextual Learning Engine (5.0 – 8.5 Days)**
   - **Phase 7.3 — Instructor Monetization & Marketplace Ledger (5.0 – 8.0 Days)**
   - **Phase 7.4 — Interactive Discussions & Project Assignments (5.5 – 9.0 Days)**
4. **Preservation of Financial Invariants:** TechSprout preserves its single-merchant SSLCommerz customer checkout model. Marketplace monetization (P7.3) is designed as an internal double-entry accounting ledger with a 14-day escrow hold period. No multi-merchant gateway routing is introduced.
5. **Infrastructure Realism & Render Pricing:** Telemetry ingestion is architected to operate safely within Render Free tier limits for MVP (using Direct PostgreSQL batch inserts with connection pooling) while providing a transparent upgrade path to Render paid tiers: Web Service Starter compute ($7.00/mo), Starter Key-Value / Redis ($10.00/mo), and PostgreSQL Flexible plans ($6.00/mo for 0.1 CPU/256MB or $19.00/mo for 0.5 CPU/1GB compute, both with 1GB included SSD storage and additional storage at $0.30/GB/mo; distinct from legacy bundled plans) to guarantee 24/7 background worker uptime and resolve waiver `WVR-P6.3-CACHE-01`. All pricing is indicative, actual deployed-plan pricing remains unverified without dashboard or invoice evidence, and infrastructure changes remain strictly prohibited.

### Official Render Pricing Model & Monthly Scenario Calculations:
1. **Pricing Model Distinctions:**
   - **Web Service Compute Pricing:** Web Service Starter compute is **$7.00/month** (0.5 vCPU, 512MB RAM, always-on).
   - **Key-Value (Redis) Pricing:** Starter Key-Value is **$10.00/month** (256MB RAM).
   - **PostgreSQL Flexible Compute Pricing:** Distinct from web compute. Render offers discrete PostgreSQL compute instances:
     - `0.1c-256mb` (0.1 CPU, 256MB RAM, 100 max connections): **$6.00/month** (includes 1GB SSD storage).
     - `0.5c-1g` (0.5 CPU, 1GB RAM, 100 max connections): **$19.00/month** (includes 1GB SSD storage).
   - **Included vs. Additional Storage:** Every flexible PostgreSQL instance includes **1GB SSD storage** in its base compute price. Additional persistent SSD storage beyond 1GB is billed separately at **$0.30 per GB/month**.
   - **Legacy Bundled Plans (Historical / Deprecated):** Render historically offered bundled PostgreSQL Starter plans at a fixed $7.00/mo (0.1 CPU, 256MB RAM, and 1GB storage). This legacy tier is no longer available for new provisions.

## 2. Deep-Dive Review by Functional Domain

### 2.1 Production Telemetry Semantic Equality (`telemetry.service.ts`)

#### Line-by-Line Code Review
Located in `apps/api/src/modules/telemetry/telemetry.service.ts` (lines 38–148, 440–475):

```typescript
export function areJsonValuesEqual(a: unknown, b: unknown): boolean {
  if (a === b) return true;
  if (a === null || b === null || a === undefined || b === undefined) return false;
  if (typeof a !== typeof b) return false;

  const aIsArr = Array.isArray(a);
  const bIsArr = Array.isArray(b);
  if (aIsArr || bIsArr) {
    if (!aIsArr || !bIsArr) return false;
    const aArr = a as unknown[];
    const bArr = b as unknown[];
    if (aArr.length !== bArr.length) return false;
    for (let i = 0; i < aArr.length; i++) {
      if (!areJsonValuesEqual(aArr[i], bArr[i])) return false;
    }
    return true;
  }

  if (typeof a === 'object') {
    const aObj = a as Record<string, unknown>;
    const bObj = b as Record<string, unknown>;
    const aKeys = Object.keys(aObj).sort();
    const bKeys = Object.keys(bObj).sort();
    if (aKeys.length !== bKeys.length) return false;
    for (let i = 0; i < aKeys.length; i++) {
      const key = aKeys[i];
      if (key !== bKeys[i]) return false;
      if (!Object.prototype.hasOwnProperty.call(bObj, key)) return false;
      if (!areJsonValuesEqual(aObj[key], bObj[key])) return false;
    }
    return true;
  }

  if (typeof a === 'number' && typeof b === 'number') {
    return Number.isNaN(a) && Number.isNaN(b);
  }
  return false;
}
```

#### Evaluation Against Review Criteria:
1. **Resolution of PostgreSQL JSONB Key-Ordering:**  
   PostgreSQL normalizes `jsonb` columns upon insertion by sorting keys internally (by length and lexicographically). When existing events are queried back from the database, key order reflects PostgreSQL storage order rather than client submission order. Sorting keys (`Object.keys(aObj).sort()`) eliminates false `IDEMPOTENCY_CONFLICT` (HTTP 409) errors previously caused by `JSON.stringify()` comparison.
2. **Preservation of Array Ordering:**  
   Lines 54–71 compare array elements strictly by index (`aArr[i]` vs. `bArr[i]`). Array sequence differences return `false`, preserving array semantics.
3. **Primitive Type Discrimination:**  
   `typeof a !== typeof b` prevents false equality between different types (e.g., `1 !== '1'`, `0 !== false`, `null !== undefined`).
4. **Missing Keys vs. Null vs. Undefined:**  
   - `{ a: 1 }` vs. `{ a: 1, b: undefined }`: Key lengths differ (`1 !== 2`), returning `false`.
   - `{ a: null }` vs. `{ a: undefined }`: Line 44 catches `null !== undefined`, returning `false`.
   - `{ a: 1 }` vs. `{ a: 1, b: 2 }`: Key lengths differ, returning `false`.
5. **Investigation of Date Value Handling (FINDING-01):**  
   - *P8.0.15 Claim:* Section 13.2 item 3 claimed `areJsonValuesEqual` *"handles dates, primitives, and nulls"*.
   - *Technical Reality:* If passed JavaScript `Date` instances, `typeof date === 'object'`, but `Object.keys(new Date())` returns `[]`. Because both have zero own enumerable properties, `areJsonValuesEqual(new Date('2026-01-01'), new Date('2026-12-31'))` evaluates to `true`, and `areJsonValuesEqual(new Date(), {})` evaluates to `true`.
   - *Operational Impact in Telemetry Ingestion:* **Zero impact.** In the telemetry pipeline, incoming payloads are parsed from JSON HTTP strings and validated by `telemetryMetadataSchema` (`apps/api/src/modules/telemetry/dto/telemetry.dto.ts:23-33`). The schema is marked `.strict()` and only allows 7 primitive numbers/booleans:
     * `watchPositionSeconds`: number
     * `previousPositionSeconds`: number
     * `totalDurationSeconds`: number
     * `playbackRate`: number
     * `score`: number
     * `passed`: boolean
     * `checkpointIndex`: number
     Because Date instances cannot exist in telemetry metadata, this edge case cannot trigger in production.
   - *Recommendation:* Update docstrings to state that `areJsonValuesEqual` operates strictly on JSON-compatible values (strings, numbers, booleans, null, arrays, plain objects).
6. **Symmetry Between Deduplication Paths:**  
   Both existing-event deduplication (lines 440–447) and intra-batch deduplication (lines 466–473) invoke `this.areMetadataEqual(a, b)` with identical comparison conditions on `courseId`, `userId`, `moduleId`, `lessonId`, `eventType`, and `occurredAt`.
7. **Conflict Detection Regression Risk:**  
   Legitimate conflicts (same `eventId` with differing `metadata`, `eventType`, or timestamps) correctly fail `isSamePayload` and trigger `IDEMPOTENCY_CONFLICT` (HTTP 409). No validation loosening exists.

## 4. Detailed Findings Register

### FINDING-01: Inaccurate Documentation Claim Regarding Date Handling in `areJsonValuesEqual`
- **Severity:** **Low**
- **Category:** Correctness / Documentation Integrity
- **Target File:** `apps/api/src/modules/telemetry/telemetry.service.ts` (lines 38–80)
- **Documentation Ref:** `docs/research/p8.0/P8.0.6_UPSTREAM_RELEASE_LINEAGE_AND_CI_STABILITY.md` (Sections 13.2 & 14.4)
- **Evidence:**  
  Running `node -e` on `areJsonValuesEqual` demonstrates:
  ```javascript
  areJsonValuesEqual(new Date('2026-01-01'), new Date('2026-12-31')) === true;
  areJsonValuesEqual(new Date(), {}) === true;
  ```
  Because `typeof date === 'object'` and `Object.keys(new Date())` produces `[]`, the function compares keys and lengths (0 === 0) and returns `true`.
- **Impact Assessment:**  
  **Zero operational risk in production.** The telemetry ingestion endpoint enforces `telemetryMetadataSchema` with `.strict()`, which allows only 7 numeric and boolean fields. Incoming JSON cannot contain Date instances. However, the claim in P8.0.15 documentation that `areJsonValuesEqual` "handles dates" is factually incorrect.
- **Reproducibility:** 100% deterministic in any JS runtime.
- **Recommended Disposition:** Non-blocking. Clarify in docstrings and documentation that `areJsonValuesEqual` operates strictly on JSON data structures, or add `if (a instanceof Date || b instanceof Date) return a instanceof Date && b instanceof Date && a.getTime() === b.getTime();` if the utility is ever exported for general application use.
